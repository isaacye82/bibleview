Guestbook

欢迎在这里留下读经心得、网站建议或彼此勉励的话。此页面预留给 GitHub Discussions 评论系统，适合 GitHub Pages、Netlify 与 Vercel 等静态托管方式。

公开留言 留言会保存在 GitHub Discussions 中，便于回复、整理与长期保留。
需要登录 访客需要使用 GitHub 账号留言，可减少垃圾信息与维护负担。
静态友好 页面本身仍是纯静态 HTML，不需要额外数据库或服务器。

留言须知

留言区将使用 GitHub Discussions 保存内容。若下方暂未显示留言框，请先在 GitHub 仓库启用 Discussions，并将 giscus.app 生成的脚本粘贴到本文件标注位置。
